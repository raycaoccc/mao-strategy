# Framework Selection Decision Tree (框架选择决策树)

Follow this tree from top to bottom. Stop at the first matching branch and load the corresponding framework reference.

---

## Primary Decision: What Is the Nature of the Problem?

### Branch A: Information Deficit (信息不足)

> "Do I know enough to make this decision?"

If NO → **Investigation Method (调查研究)**
- Load `references/investigation-method.md`
- Complete the investigation before applying other frameworks
- This branch takes priority — all other frameworks require adequate information

### Branch B: Priority Confusion (优先级混乱)

> "There are multiple problems competing for attention. Which one matters most?"

→ **Contradiction Analysis (矛盾论 + 抓主要矛盾)**
- Load `references/contradiction-analysis.md`
- Identify principal vs secondary contradictions
- Often combined with Investigation Method if the contradictions are unclear

### Branch C: Theory-Practice Gap (理论实践脱节)

> "Our plan looks good on paper but fails in reality" OR "We keep doing things without learning"

→ **Practice-Theory Cycle (实践论)**
- Load `references/practice-theory-cycle.md`
- Diagnose where the perception → conception → verification loop is broken
- Common in teams that over-plan or under-reflect

### Branch D: Long-Term Strategic Challenge (长期战略挑战)

> "This will take years. How do I pace myself?" OR "The opponent is much stronger"

→ **Protracted Strategy (论持久战)**
- Load `references/protracted-strategy.md`
- Identify which phase the contest is in (defensive / stalemate / offensive)
- Combine with Contradiction Analysis to reassess phases periodically

### Branch E: Stakeholder/Organizational Challenge (组织利益相关者挑战)

> "I need buy-in from others" OR "There is political resistance"

Two sub-branches:

**E1: Need broad input and alignment**
→ **Mass Line Feedback (群众路线)**
- Load `references/mass-line-feedback.md`
- Use when the challenge is gathering and synthesizing diverse perspectives

**E2: Need to build coalition against resistance**
→ **United Front (统一战线)**
- Load `references/united-front-alliances.md`
- Use when there are clear supporters, neutrals, and opponents to manage

**E3: Starting from very limited resources**
→ **United Front — Spark section (星星之火)**
- Load `references/united-front-alliances.md` (second half)
- Use when starting small with ambition to scale

### Branch F: Post-Action Review (事后复盘)

> "Something happened (success or failure). What do we learn?"

→ **Self-Criticism Review (批评与自我批评)**
- Load `references/self-criticism-review.md`
- Combine with Practice-Theory Cycle for forward-looking adjustments

---

## Common Combinations

| Situation | Combination | Rationale |
|-----------|------------|-----------|
| New project kickoff | Investigation + Contradiction Analysis | Gather data, then prioritize |
| Stalled initiative | Practice-Theory + Self-Criticism | Find the learning gap, then review honestly |
| Change management | United Front + Mass Line | Build coalition, gather feedback |
| Crisis response | Contradiction Analysis + Protracted Strategy | Find the core issue, plan phases |
| Post-mortem | Self-Criticism + Practice-Theory | Review honestly, extract principles |
| Resource-constrained startup | United Front (Spark) + Protracted Strategy | Start small, pace for long game |

---

## When Multiple Branches Match

If the situation fits multiple branches:

1. Start with **Branch A (Investigation)** if information is insufficient
2. Then apply **Branch B (Contradiction Analysis)** to prioritize among remaining branches
3. Select 1-2 additional frameworks based on the principal contradiction identified
4. Never apply more than 3 frameworks in a single consultation — depth beats breadth
